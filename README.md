# ECHO CITY — цифровой двойник Бишкека

Рабочий MVP городской платформы: интерактивная 3D-карта, аналитика районов, моделируемые транспортные и экологические потоки, симулятор решений, PDF-отчёты и администрирование.

Опубликованная версия: [echo-city-bishkek.russ2222.chatgpt.site](https://echo-city-bishkek.russ2222.chatgpt.site/)

## Стек

- TypeScript, React и Vinext;
- Cloudflare Workers, D1 и R2;
- MapLibre, OpenFreeMap/OpenStreetMap и deck.gl;
- Zod, Recharts, pdf-lib, Resend REST API;
- Tailwind CSS, Radix UI и Lucide.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Проверка перед публикацией:

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

## Переменные окружения

- `ADMIN_EMAILS` — список email первых администраторов через запятую;
- `RESEND_API_KEY` — ключ отправки писем;
- `REPORT_FROM_EMAIL` — подтверждённый адрес отправителя;
- `PUBLIC_APP_URL` — публичный адрес для защищённых ссылок на отчёты.

Без ключа Resend приложение использует тестовый адаптер. Публичный просмотр карты не требует входа; создание проблем, сохранение сценариев, подписки и отчёты используют Sign in with ChatGPT.

## Данные

Погода и городской фон воздуха загружаются из Open-Meteo с десятиминутным кэшем. При недоступности провайдера возвращается последний или резервный снимок с признаком устаревания. Транспорт, энергия, шум, безопасность и районные вариации явно маркируются как моделируемые. Сценарный прогноз иллюстративный и не является официальным инженерным расчётом.

Миграция D1 находится в `migrations/0001_echo_city.sql`. Конфигурация D1/R2 для Sites — в `.openai/hosting.json`.
